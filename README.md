# Codele

## Features
- Generate a new word each day and store it in the database
- Leaderboard to track top players
- Improved and responsive user interface
- IT-themed gameplay experience

## Tech Stack
- Next.js 15.4.1 (App Router)
- Tailwind CSS v4 (no tailwind.config.js)
- TypeScript
- shadcn/ui (with Tailwind integration)
- PostgreSQL + Prisma ORM
- Motion.dev for animations
